# 豆包朗读

侧边栏的“设置 → 朗读设置”可切换系统语音和豆包语音 2.0。
在火山引擎豆包语音控制台开通语音合成 2.0，将同一项目的 API Key
填入“豆包语音 API Key”，点击“保存凭证”。默认使用 VV 音色，
也可填写控制台音色库中语音合成 2.0 的音色 ID。

原文和译文共用朗读服务，分别保留语速设置。点“停止朗读”、切换文本、
切换朗读来源或关闭面板会取消语音请求和已排队的音频。
豆包采用 HTTP 流式 PCM 播放，不写入本地音频文件；支持中英文及数学公式朗读。
语音由 AI 合成。文本提交至火山引擎进行合成，费用由对应项目按服务规则结算。

凭证只保存在当前浏览器配置的扩展本地存储中，与翻译配置分开，
不包含在配置导出、发送给网页的配置消息或 Git 记录中。
